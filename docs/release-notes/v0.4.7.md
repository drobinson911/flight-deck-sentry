## Sentry 0.4.7

Sentry now finds an Overwatch box by itself, on any model, with nothing to turn on. Alerts, sounds and timing have not changed.

**The Overwatch box is always on.** The two switches ("Use the Overwatch station" and "Find it automatically") are gone. Sentry listens for the box on the network and reads its aircraft as soon as it hears one. If you never use a box, you will not see or hear anything new. If a box that was answering stops, Sentry says "Overwatch station link lost", as before. To use one box in particular, you can still type its address in Settings.

**Your own drone from the box, with no internet.** If the box hears your drone on Remote ID, Sentry can use that position for the drone you pinned. Other drones the box hears are used only to find yours; Sentry still never alerts on a drone.

**TFRs from the box, with no internet.** When Sentry cannot reach the internet, it now reads the TFRs from the box instead.
