## Sentry 0.4.6

Sentry now works with the Overwatch Micro Bar when you type its address by hand. Alerts, sounds and timing have not changed.

**A bare station address finds a Pi or a Micro Bar.** The Pi station answers on port 8080 and the Micro Bar on port 80. Before, typing just an address such as `192.168.0.133` always tried 8080, so a Micro Bar never connected unless you typed `:80`. Now, with no port typed, Sentry tries 8080 and then 80, and keeps whichever one answers with aircraft data. If the station has announced itself on the network, Sentry tries the port from that announcement first. An address with a port or a full URL works exactly as before.

**The station line shows which address answered,** for example "31 ac · 105 ms · 192.168.0.133:80". The Settings hint now says a bare address works for both the Pi and the Micro Bar.
