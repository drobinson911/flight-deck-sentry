## Sentry 0.3.4

**Settings save themselves.** Whatever you type in Settings is saved about half a second after you stop typing. If you leave Settings without tapping Save, nothing is lost. When Sentry is armed it uses the new value within a second, with no restart. This includes this controller's aircraft serial.

**Bad numbers are never saved.** If a number isn't valid or is out of range, the field turns red and shows the allowed range (for example "0.1–50 nm"). Sentry keeps using the last good value until you fix it. The alert rings must also stay in order: advisory ≥ caution ≥ warning.

**The keyboard gets out of the way.** Pressing Enter/Done, tapping Save, tapping Back, or tapping anywhere outside a field closes the keyboard. Save still applies everything at once and says "Saved".

Serials are shown and saved in capitals. Spaces around the serial and the fleet token are removed.
